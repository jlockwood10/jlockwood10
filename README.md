### `whoami`

Security researcher on the **offensive side of AI**. I break large language models
— jailbreaks, prompt injection, indirect/IPI, tool and function-call abuse — and
build the instruments that make that testing reproducible: TLS-intercepting proxies,
request replay, and automated attack runs over live LLM traffic.

Founder of **Basanos**, an independent UK AI-security practice.
