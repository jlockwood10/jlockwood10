the offensive side — jailbreaks, prompt injection (including indirect/IPI), and
tool/function-call abuse — and build the tooling that makes that testing
reproducible: intercepting proxies, request replay, and automated attack runs
over live LLM traffic.

Founder of Basanos, an independent UK AI-security practice.
